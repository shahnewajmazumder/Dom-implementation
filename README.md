
# DOM Implementation Using HTML, CSS and JavaScript

A simple and interactive web development practical project demonstrating the implementation of the Document Object Model (DOM) using HTML, CSS, and JavaScript.

The project consists of a registration form and an interactive webpage that responds to user actions through JavaScript DOM manipulation and event handling.

## 📌 Project Overview

The Document Object Model (DOM) is a programming interface that represents an HTML document as a tree of objects. JavaScript can use the DOM to access, modify, add, and remove HTML elements dynamically.

This project demonstrates how DOM manipulation makes a webpage interactive and user-friendly.

## 🎯 Objectives

- Understand the basics of the Document Object Model (DOM).
- Access and manipulate HTML elements using JavaScript.
- Handle form submissions and user inputs.
- Implement JavaScript event listeners.
- Dynamically change text and background colors.
- Create an interactive counter using buttons.
- Understand the integration of HTML, CSS, and JavaScript.

## 🧪 Experiments Demonstrated

### Experiment 1: Registration Form

**Aim:** To create a registration form and demonstrate DOM manipulation using JavaScript.

**Procedure:**
1. Create a registration form using HTML.
2. Apply CSS to style the form.
3. Access form elements using JavaScript.
4. Handle the submit event using `addEventListener()`.
5. Read user input using the `value` property.
6. Create and display registration details dynamically using DOM methods.

**Result:** The registration form accepts valid inputs and displays the submitted details dynamically on the webpage.

### Experiment 2: Interactive Page Using Buttons

**Aim:** To demonstrate DOM manipulation and event handling through interactive buttons.

**Procedure:**
1. Create buttons using HTML.
2. Access buttons and webpage elements using JavaScript.
3. Attach click event listeners.
4. Change text using `textContent`.
5. Change background colors using the `style` property.
6. Update the counter dynamically.
7. Reset the interactive elements to their initial state.

**Result:** The webpage responds dynamically to button clicks without requiring a page reload.

## 💻 DOM Concepts Used

| Method or Property | Description |
|---|---|
| `document.getElementById()` | Selects an element by its ID |
| `addEventListener()` | Registers an event handler |
| `event.preventDefault()` | Prevents the default form submission behavior |
| `.value` | Retrieves the value of a form field |
| `.textContent` | Reads or updates an element's text |
| `.style.backgroundColor` | Changes an element's background color |
| `document.createElement()` | Creates a new HTML element |
| `.append()` | Adds elements to another element |
| `.replaceChildren()` | Replaces or clears an element's children |
